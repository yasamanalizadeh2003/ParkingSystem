این پروژه مربوط به مدیریت پارکینگ است که با زبان پایتون و با استفاده از شی گرایی پیاده سازی شده است.

:قابلیت‌ها
ثبت جایگاه مخصوص خودرو
ثبت جایگاه مخصوص موتورسیکلت
حذف جایگاه خالی
نمایش جایگاه‌های خالی
ورود خودرو و موتورسیکلت به پارکینگ
جلوگیری از پارک شدن یک وسیله با پلاک تکراری
بررسی تطابق نوع وسیله نقلیه با نوع جایگاه
خروج وسیله نقلیه
نمایش وسایل نقلیه پارک‌شده
محاسبه هزینه پارکینگ بر اساس مدت توقف
محاسبه جریمه برای توقف طولانی
اعتبارسنجی پلاک خودرو با Regular Expression
اعتبارسنجی اطلاعات خودرو و موتورسیکلت
نمایش صحیح متون فارسی در ترمینال با استفاده از RTL

فایل vehicle.py شامل کلاس های مربوط به وسیله نقلیه است که با استفاده از ارث بری پیاده سازی شده اند
ویژگی‌های مشترک وسایل نقلیه مانند پلاک، نام مالک و وضعیت ورود و خروج در کلاس Vehicle قرار دارند.
کلاس ها:
Vehicle
Car
Motorcycle

فایل parking.py شامل کلاس های مربوط به پایرکینگ است که با استفاده از ارث بری پیاده سازی شده اند
این فایل مسئول مدیریت جایگاه‌ها، ورود و خروج وسایل نقلیه و محاسبه هزینه است.
کلاس ها:
ParkingSpot
CarSpot
MotorcycleSpot
ParkingLot

فایل main.py  عملیات های مربوط به پارکینگ را مدیریت می کند

برنامه از طریق  ترمینال عملیات های زیر را ارائه می‌دهد:
1. ثبت جایگاه در پارکینگ
2. حذف جایگاه
3. مشاهده جایگاه‌های خالی
4. ورود وسیله نقلیه
5. خروج وسیله نقلیه
6. مشاهده وسایل نقلیه پارک شده
7. محاسبه هزینه نهایی وسیله نقلیه
